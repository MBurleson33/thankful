            How to play Who's Thankful For That?

            Everyone secretly writes one thing they're thankful for. Then the group guesses who wrote each one.

            1. Join and write

            • The host taps Host a new game and reads out the code. Everyone joins on their own phone.
            • Write one specific thing you're thankful for. Keep it secret, and don't put your name in it.
            • Specific is more fun: "the 6am coffee before the kids wake up" beats "family."
            • The host can pick a prompt for the round, like "a small, everyday thing" or "something from this year." Write to the prompt.

            2. Read it out loud

            • The host starts the reveal. The same answer shows on every phone.
            • Someone reads it out loud so the whole table is on the same one.

            3. Talk, then vote

            • Talking is encouraged. Make your case ("that is SO Clay"), ask questions, and bluff if it's yours.
            • Everyone taps their guess on their phone. You can change it until the host reveals.
            • The writer doesn't vote. Keep a straight face!

            4. Reveal and share

            • The host taps Reveal. Everyone sees who wrote it and who guessed right. Each right guess is 1 point.
            • Then the writer gets a moment to share why they're thankful for it. This is the best part, so don't skip it.

            5. Scoreboard

            • After the last answer, the scoreboard and every answer show up. Most points gets bragging rights.
            • The host can start another round with new answers.
            Have a TV? Open TV mode (link at the bottom of the start screen, or "Show it on a TV" in the host's lobby) to show the answers, votes and scoreboard big for the whole room.
            Only one phone? Use "Pass it around instead." Each person adds an answer and hands the phone on, then the table guesses out loud.
