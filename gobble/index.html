          How to play Gobble Minds

          Don't try to be clever. Try to think like everyone else at the table.

          1. Join

          • The host taps Host a new game and reads out the code. Everyone joins on their own phone.
          • The host picks how many points win (5, 8 or 10) and starts.

          2. Answer the prompt

          • A prompt shows on every phone, like "Name a pie."
          • Type the answer you think most people will give. Keep it short and keep it secret.
          • The host can swap the prompt or type their own.

          3. Match up

          • When everyone's in, the host shows all the answers, grouped automatically.
          • If two answers mean the same thing ("pumpkin" and "pumpkin pie"), the host merges them. Talk it out as a table!

          4. Score

          • Everyone in the single biggest group gets 1 point.
          • If two groups tie for biggest, or everyone said something different, nobody scores.

          5. The turkey

          • If exactly one person gave an answer nobody else did, they get the turkey.
          • You can't win while holding the turkey. It moves to the next person who's the only one with their answer.

          6. Winning

          • The first person to reach the target score who isn't holding the turkey wins. The host can also end the game anytime, and the top score without the turkey wins.
