# 🍂 Who's Thankful For That?

A pass-the-phone gratitude guessing game for small groups.

1. Pass one phone around the table. Each person adds their name and one thing they're thankful for; their slip hides right away.
2. Start the reveal: slips come out shuffled, one at a time. Everyone guesses who wrote it, then tap to reveal.

Single static file (`index.html`), no server. Slips are saved in the phone's browser so a refresh won't lose them.

## Run it
Open `index.html`, or enable GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
